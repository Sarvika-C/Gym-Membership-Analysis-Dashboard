# 🏋️ Gym Membership Analysis Dashboard (Power BI)

An interactive **Gym Membership Analysis Dashboard** built in **Microsoft Power BI** to analyze gym membership data and uncover valuable business insights. The dashboard leverages **Power Query**, **DAX**, and interactive visualizations to monitor revenue, profit, memberships, customer status, ratings, and category performance.

---

## 📌 Project Overview

The **Gym Membership Analysis Dashboard** provides a comprehensive overview of gym operations through interactive reports and visualizations. It enables users to evaluate membership trends, monitor financial performance, analyze customer status, and identify key business insights for data-driven decision-making.

---

## 🚀 Features

- 📊 Interactive KPI Cards
- 💰 Revenue & Profit Analysis
- 👥 Total Members Overview
- ⭐ Average Customer Rating
- 📈 Year-wise Profit Trend
- 📋 Revenue, Profit & Quantity by Category
- 🏆 Profit by Membership Category
- 📊 Customer Status Analysis
- 🎛️ Interactive Region, State & Category Slicers
